## 1. ภาพรวมของหน้า Quality Report

หน้า Quality Report เป็นหน้าที่เกษตรกรใช้ดูรายงานคุณภาพการเลี้ยงปลาดุกใน **รอบการเลี้ยง** (Production Cycle) แต่ละรอบ

### สิ่งที่เกษตรกรเห็นบนหน้า (จากบนลงล่าง)

| ลำดับ | ส่วน | คำอธิบาย |
|------|------|----------|
| 1 | ตัวเลือกรอบการเลี้ยง | Dropdown เลือก "รอบการเลี้ยงที่ 1, 2, 3…" พร้อมแสดงช่วงวันที่ |
| 2 | การ์ดสรุปคุณภาพ (Hero Card) | คะแนนดาวรวม, น้ำหนักเฉลี่ยปัจจุบัน, น้ำหนักมาตรฐาน, จำนวนวันที่เลี้ยง |
| 3 | การ์ดดัชนี 4 ใบ | GPI, SR, ADG, FCR แต่ละตัวมีค่า + ระดับ (ดีมาก / ดี / ปกติ / ต่ำ / วิกฤต) |
| 4 | กราฟการเติบโต | กราฟเส้นเปรียบเทียบน้ำหนักจริง vs มาตรฐาน + แถบ ±20% |
| 5 | สรุปต้นทุน | Donut chart สัดส่วนต้นทุน + breakdown + ต้นทุนต่อตัว & ต่อกก. |

## 2. Data Flow & Architecture

```
  ┌────────────────────────────────────────────────────────────────┐
  │  URL: /quality-report?pondId=xxx&type=catfish                  │
  └────────────────────────────┬───────────────────────────────────┘
                               │
                               ▼
  ┌───────────────────────────────────────────────────────────────────┐
  │  1. ดึง Production Cycles                                         │
  │     GET /ponds/{pondId}/cycles                                     │
  │     → ได้ cycles[] (id, startDate, endDate, …)                    │
  └───────────────────────────────┬───────────────────────────────────┘
                                  │
                                  ▼
  ┌───────────────────────────────────────────────────────────────────┐
  │  2. ดึง Records ของรอบที่เลือก                                     │
  │     GET /records?productionCycleId={id}&limit=500                  │
  │     → ได้ records[] (date, avgWeight, mortality, foodAmount, …)   │
  └───────────────────────────────┬───────────────────────────────────┘
                                  │
                                  ▼
  ┌───────────────────────────────────────────────────────────────────┐
  │  3. คำนวณ Quality Assessment                                       │
  │     computeQualityAssessment(records, farmType)                    │
  │     → QualityAssessment object (20+ fields)                        │
  └───────────────────────────────┬───────────────────────────────────┘
                                  │
                     ┌────────────┼────────────┐
                     │            │            │
                     ▼            ▼            ▼
              ┌──────────┐ ┌───────────┐ ┌────────────┐
              │ Summary  │ │  Growth   │ │    Cost    │
              │  Cards   │ │  Chart    │ │  Summary   │
              └──────────┘ └───────────┘ └────────────┘
```

### ข้อมูลที่ต้องการจาก API

**Cycle API:**
- `id`, `startDate`, `endDate`, `initialFishCount`, `released`

**Record API (แต่ละ record):**
- `date` — วันที่บันทึก
- `averageFishWeight` — น้ำหนักเฉลี่ยปลา (กรัม)
- `mortality` — จำนวนปลาตาย
- `foodAmount` — ปริมาณอาหาร (กก.)
- `foodCost` — ค่าอาหาร (บาท)
- `medicineCost` — ค่ายา (บาท)
- `pelletFoodCost`, `freshFoodCost` — ต้นทุนอาหารเม็ด & อาหารสด (บาท)

## 3. โมเดลการเติบโต Gompertz

ระบบใช้ **Gompertz Growth Model** เป็นเส้นมาตรฐานในการเปรียบเทียบการเติบโตของปลา

### สูตร

```
W(t) = Wmax × (W0 / Wmax)^(e^(-L × t))
```

| พารามิเตอร์ | ค่า | ความหมาย |
|-------------|------|----------|
| `Wmax` | 1,200 กรัม | น้ำหนักสูงสุดที่ปลาดุกจะเติบโตถึง |
| `W0` | 0.5 กรัม | น้ำหนักเริ่มต้นของลูกปลา |
| `L` | 0.018 | อัตราการเติบโต (growth rate constant) |
| `t` | ตัวแปร | จำนวนวันนับจากวันปล่อยปลา |
| `TOLERANCE` | ±20% | ช่วงยอมรับ (แถบสีเขียวบนกราฟ) |

### ตัวอย่างน้ำหนักมาตรฐาน

| วัน (t) | น้ำหนักมาตรฐาน (กรัม) |
|---------|----------------------|
| 7 | ~0.57 |
| 30 | ~0.85 |
| 60 | ~1.44 |
| 90 | ~3.49 |
| 120 | ~11.67 |
| 150 | ~47.89 |
| 180 | ~176.25 |
| 210 | ~442.57 |
| 240 | ~729.74 |
| 270 | ~928.01 |
| 300 | ~1,044.67 |

> **หมายเหตุ:** ค่าเหล่านี้คำนวณจากสูตร Gompertz ด้วยพารามิเตอร์ข้างต้น

### ADG มาตรฐาน (Standard ADG)

ระบบคำนวณ ADG มาตรฐานด้วยอนุพันธ์ของ Gompertz:

```
ADG_standard(t) = W(t) × L × ln(Wmax / W(t))
```

ใช้สำหรับเปรียบเทียบว่า ADG จริงอยู่ในเกณฑ์ดีหรือไม่

## 4. ดัชนีคุณภาพทั้ง 4 ตัว

### 4.1 GPI — Growth Performance Index (ดัชนีประสิทธิภาพการเติบโต)

**ความหมาย:** บอกว่าปลาโตเร็วกว่าหรือช้ากว่ามาตรฐานเท่าไหร่ เป็น **%**

**สูตร:**
```
GPI = (น้ำหนักเฉลี่ยจริง ÷ น้ำหนักมาตรฐาน Gompertz) × 100
```

**ตัวอย่าง:** ถ้าน้ำหนักจริง 120g ที่วันที่ 200 และมาตรฐานคือ 100g → GPI = 120%

**เกณฑ์การประเมิน:**

| ระดับ | ค่า GPI | สี | Badge |
|-------|---------|-----|-------|
| ดีมาก (excellent) | ≥ 110 | เขียว | ดีมาก ⭐ |
| ดี (good) | ≥ 100 | เขียวอ่อน | ดี |
| ปกติ (normal) | ≥ 90 | เหลือง | ปกติ |
| ต่ำกว่าเกณฑ์ (below) | ≥ 80 | ส้ม | ต่ำกว่าเกณฑ์ |
| วิกฤต (critical) | < 80 | แดง | วิกฤต ⚠️ |

**คำแปลสำหรับเกษตรกร:**
- GPI ≥ 100 = "ปลาโตเร็วกว่าหรือเท่ามาตรฐาน"
- GPI < 100 = "ปลาโตช้ากว่ามาตรฐาน"

---

### 4.2 SR — Survival Rate (อัตราการรอดตาย)

**ความหมาย:** สัดส่วนปลาที่ยังมีชีวิตอยู่ เป็น **%**

**สูตร:**
```
SR = ((จำนวนปลาเริ่มต้น − จำนวนตายสะสม) ÷ จำนวนปลาเริ่มต้น) × 100
```

**เกณฑ์การประเมิน:**

| ระดับ | ค่า SR | สี |
|-------|--------|-----|
| ดีมาก (excellent) | > 90% | เขียว |
| ดี (good) | > 80% | เขียวอ่อน |
| ปกติ (normal) | > 70% | เหลือง |
| วิกฤต (critical) | ≤ 70% | แดง |

**หมายเหตุ:** SR จะถูกปัดเป็นทศนิยม 1 ตำแหน่ง

---

### 4.3 ADG — Average Daily Gain (อัตราการเพิ่มน้ำหนักเฉลี่ยต่อวัน)

**ความหมาย:** ปลาโตขึ้นวันละกี่กรัม

**สูตร:**
```
ADG = น้ำหนักเฉลี่ยปัจจุบัน ÷ จำนวนวันที่เลี้ยง
```

**หน่วย:** กรัม/วัน (แสดงทศนิยม 2 ตำแหน่ง)

**เกณฑ์การประเมิน:**

| ระดับ | เงื่อนไข |
|-------|---------|
| ดีมาก (excellent) | ADG ≥ ADG_standard × 1.1 |
| ดี (good) | ADG ≥ ADG_standard × 0.9 |
| ปกติ (normal) | ADG ≥ ADG_standard × 0.7 |
| ต่ำกว่าเกณฑ์ (below) | ADG ≥ ADG_standard × 0.5 |
| วิกฤต (critical) | ADG < ADG_standard × 0.5 |

> ADG_standard คำนวณจากอนุพันธ์ Gompertz (ดูหัวข้อ 3)

**สิ่งที่แสดงเพิ่ม:** ใต้ค่า ADG จะแสดง "มาตรฐาน: X.XX ก./วัน" เพื่อให้เปรียบเทียบได้

---

### 4.4 FCR — Feed Conversion Ratio (อัตราการเปลี่ยนอาหารเป็นเนื้อ)

**ความหมาย:** ให้อาหารกี่กิโลกรัมเพื่อให้ได้เนื้อปลาเพิ่ม 1 กิโลกรัม → **ยิ่งต่ำยิ่งดี**

**สูตร:**
```
FCR = น้ำหนักอาหารทั้งหมด (กก.) ÷ น้ำหนักปลาทั้งหมดที่เพิ่มขึ้น (กก.)

โดย:
- น้ำหนักอาหาร = ผลรวม foodAmount จาก records ทั้งหมด (กก.)
- น้ำหนักปลาเพิ่ม = (น้ำหนักเฉลี่ยปัจจุบัน × จำนวนปลาที่รอด) ÷ 1000 (กก.)
```

**เกณฑ์การประเมิน:**

| ระดับ | ค่า FCR |
|-------|---------|
| ดีมาก (excellent) | ≤ 1.5 |
| ดี (good) | ≤ 2.0 |
| ปกติ (normal) | ≤ 2.5 |
| ต่ำกว่าเกณฑ์ (below) | ≤ 3.0 |
| วิกฤต (critical) | > 3.0 |

**หมายเหตุ:** 
- FCR จะแสดงเป็น `null` ถ้าน้ำหนักปลาที่เพิ่มขึ้น ≤ 0
- ยิ่ง FCR ต่ำ = เกษตรกรประหยัดค่าอาหารมากขึ้น

## 5. ระบบคะแนนดาวรวม (Overall Stars)

คะแนนดาวรวมคำนวณจาก **ค่าถ่วงน้ำหนัก** (weighted average) ของ 3 ดัชนี:

### สัดส่วนน้ำหนัก

| ดัชนี | น้ำหนัก | เหตุผล |
|-------|---------|--------|
| GPI | 60% | การเติบโตเป็นตัวชี้วัดหลัก |
| SR | 25% | อัตราการรอดสำคัญรองลงมา |
| FCR | 15% | ประสิทธิภาพอาหาร |

> **หมายเหตุ:** ADG ไม่ถูกนับแยก เพราะถือว่าสะท้อนอยู่ใน GPI อยู่แล้ว

### การแปลงคะแนนดาวจากแต่ละดัชนี

**GPI → ดาว:**

| GPI | ดาว |
|-----|-----|
| ≥ 120 | 5.0 |
| ≥ 110 | 4.5 |
| ≥ 100 | 4.0 |
| ≥ 95 | 3.5 |
| ≥ 90 | 3.0 |
| ≥ 85 | 2.5 |
| ≥ 80 | 2.0 |
| ≥ 70 | 1.0 |
| < 70 | 0.5 |

**SR → ดาว:**

| SR | ดาว |
|----|-----|
| ≥ 95 | 5.0 |
| ≥ 90 | 4.5 |
| ≥ 85 | 4.0 |
| ≥ 80 | 3.5 |
| ≥ 75 | 3.0 |
| ≥ 70 | 2.5 |
| ≥ 60 | 2.0 |
| ≥ 50 | 1.5 |
| < 50 | 1.0 |

**FCR → ดาว:**

| FCR | ดาว |
|-----|-----|
| ≤ 1.2 | 5.0 |
| ≤ 1.5 | 4.5 |
| ≤ 1.8 | 4.0 |
| ≤ 2.0 | 3.5 |
| ≤ 2.5 | 3.0 |
| ≤ 3.0 | 2.5 |
| ≤ 3.5 | 2.0 |
| ≤ 4.0 | 1.5 |
| > 4.0 | 1.0 |

> ถ้า FCR เป็น `null` → ใช้เฉพาะ GPI (70%) + SR (30%)

### สูตรสุดท้าย

```
rawStars = (GPI_stars × 0.60) + (SR_stars × 0.25) + (FCR_stars × 0.15)
overallStars = ปัดเป็น 0.5 ที่ใกล้ที่สุด (เช่น 3.7 → 3.5, 3.8 → 4.0)
```

## 6. ระยะปลาและขนาดตลาด

### ระยะปลา (Fish Stages)

ระบบแบ่งปลาออกเป็น 3 ระยะตามน้ำหนัก:

| ระยะ | ชื่อไทย | ช่วงน้ำหนัก | ช่วงอายุโดยประมาณ |
|------|---------|-------------|-------------------|
| SMALL | ปลาตุ้ม | 0.5 – 5 กรัม | 7 – 10 วัน |
| LARGE | ปลานิ้ว | 5 – 30 กรัม | 11 – 30 วัน |
| MARKET | ปลาตลาด | > 30 กรัม | 31 – 180 วัน |

### ขนาดตลาด (Market Sizes)

| ระดับ | น้ำหนักขั้นต่ำ | ความหมาย |
|-------|---------------|----------|
| ขนาดตลาดทั่วไป (GENERAL_MIN) | 150 กรัม | ขายได้ในตลาดปกติ |
| ขนาดพรีเมียม (PREMIUM_MIN) | 500 กรัม | ขายได้ราคาสูง |

| ปริมาณอาหารที่ใช้ | — | แสดงเป็น กก. (ไม่มี bar) |

#### Stat Pills (การ์ดสรุปต้นทุนเฉลี่ย)
| การ์ด | สี | ค่า |
|-------|-----|-----|
| ต้นทุนต่อปลา 1 ตัว | เขียวเข้ม | X.XX บาท |
| ต้นทุนต่อปลา 1 กก. | น้ำเงิน | X.X บาท |

**สูตร:**
```
ต้นทุนต่อตัว (costPerFish)
  = ต้นทุนทั้งหมด ÷ จำนวนปลาที่รอด

ต้นทุนต่อกก. (costPerKg)
  = ต้นทุนทั้งหมด ÷ (น้ำหนักเฉลี่ย × จำนวนปลาที่รอด ÷ 1000)
```
